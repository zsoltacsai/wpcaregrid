- **BLOCKED — background activity:** the HTTP gate does not by itself prove background workers or scheduler are fenced. The release checklist makes persistent worker/scheduler fencing an independent gate.
- **BLOCKED — migration/recovery:** marketing-only does not skip the controller's migrations. The release checklist requires backup, isolated restore and migration rehearsal before using the controller.
- **Not assessed:** legal/accounting, live dependency advisories, host configuration, operational monitoring, and any production data or credentials.
