## Explicitly separate

Laravel server PHP 8.4/MySQL CI facts are platform deployment evidence only. They do not set customer-host support minima. Connector real-WordPress CI currently uses WordPress 7.1.x and Composer test PHP `^8.2`; plugin metadata requires PHP 8.1. The approved customer floor and tested support envelope remain to be resolved by release-specific fixture coverage.
