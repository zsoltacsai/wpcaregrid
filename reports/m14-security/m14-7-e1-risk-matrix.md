## Open side-effect boundary

The scan completion path calls `IncidentService::openForDetection`. Repository source sets incident auto-open and auto-backup defaults to true. Therefore E2-02/E2-05 are **BLOCKED** until effective settings, backup destination, notifications, and queue behavior are known and any allowed side effects are explicitly bounded. A label such as “detection-only” does not remove this effect. A scan cancellation cannot undo database writes, incident creation or backup requests already made. M147-F04 remains open.

## Recovery boundary

The deployment script's guarded code rollback is not a database or filesystem restore. A database restore, filesystem restore, Connector rollback, cleanup and full environment recovery each have distinct preconditions and approvals. Live backup recency, isolation, capacity and restore readiness are unknown; any operation whose blast radius cannot be kept to the approved synthetic target is NO-GO.
