## Scenario sequencing

1. Normal staging baseline and gate read-back precede any isolated provisioning.
2. Run A–F with report-only/no-delete semantics; keep artifacts isolated.
3. Run G–K using explicit synthetic fixtures and fake provider only.
4. Capture immutable T0 before G; run L in separate recovery DB, then M/N failure and boundary tests.
5. Run O cleanup and health verification last. If any safety gate, tenant boundary or recovery invariant fails, stop the run and preserve only redacted evidence.

## Non-claims

Scenario completion is technical test evidence only. It does not approve legal copy, acceptance enforcement, retention duration, physical object erasure, production anonymization, or a provider's delete semantics.
