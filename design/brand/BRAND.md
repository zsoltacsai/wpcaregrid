# WP CareGrid Brand Guidelines

## Brand

Name: WP CareGrid
Domain: https://wpcaregrid.com
Primary descriptor: WordPress Maintenance
Primary tagline: WordPress maintained. Website working.

## Brand personality

Professional, technical, reliable, straightforward, experienced, calm and practical.

Avoid anything that feels futuristic, flashy, crypto/Web3, gaming-oriented, generic SaaS, or AI-generated.

The brand should feel like a technical service run by experienced WordPress developers.

## Visual direction

- Clean editorial layouts
- Strong typography
- Off-white backgrounds
- Dark navy typography
- Muted green accent
- Thin borders
- Subtle shadows
- Real product UI
- Technical interface details

Avoid gradients, glassmorphism, neon, decorative blobs, excessive rounded cards, 3D illustrations, stock developer photography, and excessive animation.

## Typography

Primary: IBM Plex Sans
Secondary: IBM Plex Mono

IBM Plex Mono is for technical metadata, timestamps, version numbers, IDs and logs only.

## Logo

The logo consists of:
- a 3x3 grid of rounded-square elements
- one muted-green accent square
- the WP CareGrid wordmark

The grid represents multiple connected websites and central management.

Preferred horizontal construction:
[grid] WP CareGrid

The descriptor "WORDPRESS MAINTENANCE" is optional and should only be used at sufficient sizes.

Do not add a WordPress logo or generic shield symbol to the main logo.

## Status system

Healthy / success: #5B8C72
Attention / warning: #C58A32
Critical: #C84735

Use status colors as functional signals, not decorative colors.

## UI principles

Clarity > decoration
Real UI > illustration
Specific information > marketing language
Subtlety > visual effects
