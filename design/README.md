# WP CareGrid Brand Pack

Brand: WP CareGrid
Domain: wpcaregrid.com

## Contents

- design/brand/BRAND.md — approved brand rules
- design/brand/DESIGN_TOKENS.css — color/spacing tokens
- design/brand/color-palette.txt — palette + typography reference
- design/CLAUDE_BRAND_NEXT_STEP.md — prompt for the next Claude Code step
- logo/ — light/dark horizontal and stacked SVG + PNG logos
- icons/ — favicon and app icon SVG + PNG
- design/brand-board.png — original brand board reference
- design/brand-board-refined.png — refined brand reference

## Fonts

The brand uses IBM Plex Sans and IBM Plex Mono. Font files are intentionally not included in this pack. The web project should load them through an approved web-font strategy or self-host them separately.
